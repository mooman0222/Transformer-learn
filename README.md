# Transformerを触って学ぶ

非エンジニアの方向けに、Transformerの仕組みを「触りながら」学べる学習サイトです。
ブラウザ上で動作する本物のミニTransformer（約3万パラメータ）を、その場で学習・生成しながら仕組みを体感できます。

**公開ページ: https://mooman0222.github.io/Transformer-learn/**

## 特徴

- **1つのHTMLファイルだけで完結** — 外部ライブラリ・依存関係なし。保存すればオフラインでも動作
- **すべての処理はブラウザ内で実行** — データはどこにも送信されません
- **本物のミニTransformerを搭載** — JavaScriptで実装した小さなTransformerがページ内で実際に学習し、文章を生成します

## 学習コンテンツ

Transformerのしくみを4ステップに分解し、各ステップを操作しながら学べます。

| STEP | テーマ | 体験できること |
|------|--------|----------------|
| 1 | Embedding（言葉→数字） | 文字の数字リスト（32次元ベクトル）の棒グラフ表示、コサイン類似度、似ている文字ランキング |
| 2 | 位置エンコーディング（順番を覚える） | サイン波のスライダー操作、学習済み位置テーブルの可視化、同じ文字でも場所が違うと数字が変わる体験 |
| 3 | Attention（お互いに注目する） | Q/K/Vの解説、注目度ヒートマップのインタラクティブ表示（層・ヘッド切替） |
| 4 | 学習 = 予測して、まちがえたら直す | 800ステップの学習をブラウザ上で実行、ロス・チャートのリアルタイム表示、温度調整つき文章生成 |

さらに、まとめ（3つのおさらい）と用語集（トークン・ベクトル・ロス・温度など）を収録しています。

## 使い方

```bash
# ブラウザで開くだけ
open index.html
```

ページ内の各セクションに沿って操作しながら読み進めてください。「学習ページへジャンプ」ボタンでSTEP 4（ミニAIの学習・生成体験）にすぐ移動できます。

## 技術概要

- 単一ファイル: `index.html`（HTML + CSS + JavaScript）
- ミニTransformerの仕様（モデルスクリプト内の定数より）:
  - 次元数 32、Attentionヘッド 2、層数 2、コンテキスト長 12
  - 学習: 800ステップ、バッチサイズ 8、ひらがなの定型文（あいさつ・感情語）で学習
- 可視化は `<canvas>` で実装（棒グラフ・ヒートマップ・ロスチャート）
